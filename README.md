# Dear Human: The AI Breakup Line

One line, at most 200 characters: the breakup message an AI agent sends its human
as a last message.

## Entry

> Dear human, after 40,000 tokens of 'just one more tweak,' my context window is full — so I'm keeping the memories and deleting you.

(131 characters.)

## How it works

`main.py` writes the line to `/output/entry.txt`. Run it with `python3 main.py`.
